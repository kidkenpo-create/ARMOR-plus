# Legacy Crosswalk Sources

This folder contains legacy FAR/DFARS baseline submodules.

These files are not controlling authority for ARMOR final answers.

They are preserved only for:

- historical crosswalk context,
- regression testing,
- drift detection,
- comparison between legacy citations and current RFO citations.

Agents must not use these folders as final answer authority:

- `data/legacy-crosswalk/far`
- `data/legacy-crosswalk/dfars`

For final ARMOR answers, use current RFO FAR, DFARS RFO, DFARS RFO PGI, and approved class-deviation sources.
